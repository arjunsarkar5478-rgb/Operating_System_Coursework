Project Overview

This is a technical journal of my 7 weeks experience during designing, deploying, securing and testing a Linux server infrastructure. This coursework was essentially aimed at modeling a real-life situation in system administration by creating a headless Ubuntu server which could be controlled remotely over a secure SSH connection. 
I did not merely install an operating system, but created a two-system network: a secure "Workstation" which serves as a bastion host, and a target "Server" which is a closed network. In seven weeks, I hardened the security of the server, deployed firewalls, developed automation scripts, and conducted severe stress testing to study the trade-offs between the security and the performance of the system.
This journal is a testament to my practical implementation process, problem solving, and critical thinking about the contemporary operating system management.
